# Alien Assault asset provenance

All Phase 8 presentation is original placeholder content authored for this project.

- Ship: transformed engine basic cone, cyan unlit material.
- Enemies: flattened engine basic spheres, magenta unlit material, original two-row formation motion.
- Projectiles and arena boundaries: engine basic spheres/cubes with original emissive colors.
- Destruction cue: locally synthesized 0.14-second decaying electronic tone, generated by
  `Scripts/Editor/create_phase8_assets.py`; no sampled recordings or external music.
- HUD: native shared presentation widget with game-specific heading, controls and status.

Engine basic meshes are supplied with Unreal Engine. No purchased assets, external game
characters, copied layouts, textures, recordings or third-party asset packs are used.
